# SI World Design v0.1

## 1. Purpose

本文是当前 SI-001 世界空间规划的人类可读 source of truth，整理已明确的世界设定及尚未决定的事项。它记录的是设计，不是可直接查询的 runtime world database。

**World Design ≠ Runtime World Seed。** `data/worlds/si_world.yaml` 仅包含已经进入 B4 runtime 的最小地点及固定 UUID。World Design 也可以记录已确认、但尚未进入 runtime 的规划地点；设计中出现地点不表示它已创建为 World Entity。

## 2. Design Principles

- 世界遵循正常的现实物理规律；世界观和实际模拟范围分开管理。
- 这是正常的现代城市生活环境，允许玲拥有不围绕 Azusa 展开的独立生活空间。
- 世界不是围绕用户存在。用户参与某些经历，不代表所有地点和生活都以用户为中心。
- 不为了满足当前软件功能而无限扩张设定；只补充理解空间关系和生活连续性所需的内容。
- 优先保持地点关系和生活空间的连续性，不提前把未确定的细节写成事实。

## 3. Current World Overview

整体是正常的现代城市/城区，有较多年轻人生活。它不是纯乡村或传统小镇：主城区更现代、繁华，夜间可以比较热闹。住宅区本身相对安静，其车站附近另有一小片偏“小镇感”的日常商业区域。

现阶段不确定城市名称、人口、城市等级、国家、地区或行政区划；本节不为这些事项补值。

## 4. Major Areas

### 4.1 教育生活区

教育生活区和学校已经明确存在。学校是玲当前生活的重要地点。该区域处于绿色、低至中密度、教育与生活空间相结合的城区环境；更具体的现实参照及氛围记录见 [Character Design](character/character-design.md)。

本文件不据此创建班级、教室、课程表、校园 NPC 或完整校园地图。

### 4.2 住宅区

存在相对安静的住宅区，玲的家位于其中。住宅区和学校共同构成她目前主要生活区域的重要部分。本设定不进一步确定家所在的门牌、楼层、房型或邻居。

### 4.3 住宅区商业区域

住宅区车站附近存在一小片偏“小镇感”的商业区域。它以日常生活为导向，规模不大，适合步行、买东西和闲逛；整体氛围与繁华主城区不同。具体店铺和品牌未确定。

### 4.4 主城区

城市中存在规模更大、现代城市感更明显的繁华主城区，夜间可以比较热闹。Character Design 还记录了城市中心与主要生活区域之间“数站轨道交通、约 15–25 分钟”的概略关系；这不是线路、站点或精确地图数据。主城区的精确位置、设施清单以及是否包含 CBD、行政中心等结构尚未确定。

### 4.5 海岸

城市具有海岸区域，已明确两种氛围不同的海边：

- **公共海滩**：较开放、人可能较多，可以热闹，属于正常公共活动区域。
- **隐蔽海滩**：更安静、人更少，位于住宅区一侧矮丘陵的另一面。

“隐蔽”描述空间和氛围，不表示它是秘密、私人或危险地点。公共海滩的具体位置、两处海滩的精确关系和可达方式仍待确定。

### 4.6 丘陵 / 高地

住宅区一侧存在较低的丘陵或高地，是偏自然的地形而非高山。它在空间上部分隔开住宅区与隐蔽海滩。山与住宅区之间有一定非城市化/自然区域。

## 6. Spatial Relationships

当前已确定的是相对空间意图，而不是可用于导航的地图：

- 住宅区与学校都位于/关联于教育生活区的主要生活空间；玲的家位于住宅区。
- 住宅区车站附近有一小片日常商业区；其氛围与主城区不同。
- 住宅区一侧有较低丘陵/高地；住宅区与丘陵之间有一定自然区域。
- 隐蔽海滩位于该丘陵/高地的另一面；公共海滩与它在开放程度和人流氛围上不同。
- 高地面海的一侧倾向安排在西侧，以形成观看海上夕阳的视野；另一侧希望可以看到学校方向的早晨景色。
- 朝向学校的一侧可以形成朝阳视野。
- 高地/海岸附近存在灯塔的设计方向；灯塔是否废弃尚未冻结。

这些方向主要描述此前使用“上/下/左/右”规划空间时形成的相对关系。地图整体的绝对朝向尚未最终冻结，不能据此推出完整的东南西北方位、坐标、距离、道路、线路或精确地图。

## 7. Character Relationship to the World

玲生活在该世界中，但世界事实、角色知识、角色记忆和角色经历是不同层次：

**World Truth ≠ Character Knowledge ≠ Character Memory ≠ Character Experience**

World Design 中描述某地点，不代表它已经进入 runtime。World Seed 中有地点，不代表玲已经去过、知道其全部信息或记得相关经历。World entity 的描述也不会自动成为 Character Knowledge；实际经历需要相应事实与明确记录支持。

## 8. Runtime Status

当前 B4 runtime seed 文件为 `data/worlds/si_world.yaml`，只包含四个固定 UUID 地点：

- 教育生活区
- 住宅区
- 住宅区的家（parent 为住宅区）
- 学校

其余本设计文档所列地点——住宅区车站附近的小商业区、主城区、公共海滩、隐蔽海滩、丘陵/高地和灯塔——目前均为 **Design-only**，尚未加入 runtime seed。此状态表示实现范围，不表示对这些地点的世界观设定被否定。

## 9. Open Questions

以下事项保留待定，不由本版代为决定：

- 城市名称、国家/地区、城市等级、人口和行政区划；
- 地图整体朝向，以及相对方位如何映射到绝对方向；
- 主城区与住宅区的精确距离和位置；
- 学校名称及详细空间结构；
- 灯塔的具体形式及是否废弃；
- 公共海滩的具体位置，以及海岸的细部空间关系；
- 住宅区商业区域的具体店铺组成；
- 公共交通线路及其详细走向；
- 世界中的其他居民、组织或 NPC；
- 住宅区、家、学校及其他地点尚未在本版明确的细节。

## 10. Expansion Rules

后续增加世界内容时，依次明确：

1. 先在 World Design 中定义或确认该设定；
2. 再决定它是否需要进入 Runtime World Seed；
3. 再判断 Character 是否有依据知道它；
4. 再判断 Character 是否实际经历，以及是否形成可支持的记忆。

不能从“World Seed 中存在地点”直接推导“Character 已经经历该地点”。未确定事项继续标为待定，不能以合理推测补成设定。
