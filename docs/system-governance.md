# System Governance

> 系统治理

本文档定义系统、开发者与 Character 之间的权限和控制关系。

System Governance 与 Character Constitution 相互独立：

- Character Constitution 描述 Character 是谁以及如何变化；
- System Governance 描述系统能够做什么以及开发者拥有什么权限。

系统限制不得伪装为 Character 自身的人格、记忆或价值观。

## Planned Areas

后续将逐步定义：

### G0 — Developer Authority

开发者权限。

### G1 — Runtime Permissions

运行时权限与能力边界。

### G2 — Privacy

Character、用户及运行数据的隐私规则。

### G3 — Modification Protocol

Character 状态和核心设计的修改规则。

### G4 — Backup and Migration

备份、恢复、迁移及身份连续性。

### G5 — Safety

系统安全机制。

### G6 — Emergency Authority

异常情况下的紧急控制机制。

### G7 — Autonomy Transition

随着未来系统自主性与技术能力发展，对权限关系进行调整的机制。

具体条款将在后续设计过程中逐条审议。
